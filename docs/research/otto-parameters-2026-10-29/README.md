## Coverage

- All 49 category sitemap files were scanned successfully.

- 276 query names occur in those sitemap URLs.
- Live sorting and price interactions confirmed two additional URL names: `sortiertnach` and `selektion`.
- 58 browser observations included 56 readable pages and 40 observations with rendered filter fields. Two observations timed out.

This is a complete inventory of names in the scanned published sitemap corpus, supplemented by observed controls and two live interactions. It is not an exhaustive specification of OTTO's backend, every category's rendered controls, every valid option, or every valid combination. Listing paths include audience and brand variants and are not a deduplicated category taxonomy. A parameter found on one category is not proven valid on another. Sample values are examples, not complete allowed-value lists.

## Compound selection and range fields

Selecting price up to 100 euros in the Fitnessgeräte category produced a root URL with a `selektion` parameter containing `(bis.preis-in-eur.100)`, category predicates, and a version marker. Sorting remained a separate `sortiertnach=preis-aufsteigend` query key. The original named price input contained `_,100`.

The example demonstrates that a control name such as `preis-in-eur` need not appear as a top-level query key. The observed expression used `und`, `oder`, `bis`, `ist`, `sind`, and a version structure. This single observation does not establish the full expression grammar or safe replay support.

Published URLs also use bounded keys such as `hoehe-in-cm~ab` and `hoehe-in-cm~bis`. Other range fields may use compound selection syntax or other encodings. Do not invent every possible suffix combination from a base field name.

## Collection boundaries

The browser inspected all 42 single-segment department paths present in the published listing-path set, a television category, fourteen additional category pages, and a sorting observation. Some department paths redirect or display landing pages without filter controls. Empty observations do not prove that the department has no filters. The Möbel and Wohnen root observations timed out; the Sofas subcategory was read successfully. The scanner did not enumerate every filter option or visit all 8,624 listing paths in the browser.

Internal hidden form fields, authentication, account, checkout, and tracking controls were excluded from the browser field inventory. Published query names were retained as observed, including unusual spellings such as `spoartart` and `reduziertstil`; they have not been silently corrected or certified as current supported filters.

The extension classification in the JSON describes its current route parser, not successful Save or verified replay. Generic classification alone does not establish a safe control mapping. No extension source was changed for this inventory.
